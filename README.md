# Pollux Asistan 🇹🇷

Çevrimdışı öncelikli Türkçe asistan — iki sürüm tek beyin:

| Sürüm | Kurulum |
|---|---|
| **CMD (bilgisayar)** | `npm install -g pollux-asistan` sonra `pollux` yaz |
| **Android (telefon)** | Aşağıdaki **Releases** bölümünden `PolluxAsistan.apk` indir, üstüne kur |

## CMD kullanımı

```sh
pollux                  # ekran uygulaması (logo + sohbet + My Links)
pollux --chat           # klasik satır sohbeti
pollux "saat kaç"       # tek soru-cevap
pollux "notepad aç"     # uygulama açar
pollux "youtube aç"     # siteyi uyarıyla açar
```

2500+ kayıt bilgi bankası, 800+ çift sözlük, hesap/birim/plaka/burç, uygulama+site açma, gündem, canlı döviz/hava durumu, yapay zeka araştırması — hepsi Türkçe.

## Klasörler

- `cmd/` — Node.js CMD sürümü (npm paketi kaynağı)
- `android/` — Android Studio projesi (paket: `com.polluxasistan.app`)
